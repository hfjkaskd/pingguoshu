需要留意的一个细节

BizzaLogModule.cs:22 使用 Random.Range(0, 10) <= 1。Unity 的整数上限不包含 10，因此实际命中 0、1 两种结果，即约 20%；但旁边注释写的是 10%。如果目标确实是 10%，这里应改成 Random.Range(0, 10) == 0 或调整采样逻辑。
